## 1. Theoretical Framework

The value of a currency protocol emerges from the network’s role in facilitating trade. Linear scaling (elasticity ≈ 1.0) proves that value scales **linearly** with economic activity, contradicting Metcalfe’s Law ($V \propto n^2$) for currency networks.

### Core Equation
**P = Max(R, N, S)**

Where:
- **P**: Price
- **R**: Redemption utility (≈ 0 for fiat)
- **N**: Network utility (Dominant in stable regimes)
- **S**: Speculative utility

## 3. Convergence Analysis

When normalized by GDP per capita, network utility converges toward a fundamental constant. Despite absolute utility varying by a factor of 22 between developed ($10.5K) and developing ($0.5K) economies, **normalized utility varies only by a factor of 2** ($161 vs $81–$113).
